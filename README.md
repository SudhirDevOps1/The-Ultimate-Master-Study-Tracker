## 🛡️ Enterprise Auto-Updater & Zero Data Loss Architecture

FlowTrack Pro features an enterprise-grade automated update pipeline engineered to deliver seamless upgrades while guaranteeing **100% zero data loss**:

```
┌────────────────────────────────────────────────────────┐
│               GitHub Release Published (v0.2.4)        │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│       Electron Background Auto-Updater Service         │
│     (Checks every launch & 6h via GitHub API)          │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│     In-App Floating Pill & Interactive Modal           │
│   • Version delta (Current v0.2.3 ➔ Target v0.2.4)     │
│   • Live Changelog, Features & Bug Fixes View          │
│   • 1-Click "Restart & Install Update" or Snooze       │
└──────────────────────────┬─────────────────────────────┘
                           │
                           ▼
┌────────────────────────────────────────────────────────┐
│          100% ZERO DATA LOSS GUARANTEE                 │
│   • Pre-update memory flush hook: saveLogToFile()      │
│   • Binaries updated in: %LOCALAPPDATA%/Programs/...   │
│   • All user databases, IndexedDB, study notes, and    │
│     activity history in %APPDATA%/FlowTrackPro are     │
│     completely untouched, safe, and persistent!        │
└────────────────────────────────────────────────────────┘
```

### 💎 Key Update Capabilities:
1. **Silent Background Check & Download**: Verifies new releases from GitHub Releases API without blocking your focus.
2. **Interactive Changelog Reviewer**: Read what is new, bug fixes, and performance improvements before applying the update.
3. **Pre-Update Memory Flush**: Automatically writes any ongoing study session and window tracking buffer to disk before restarting.
4. **Permanent Data Preservation**: All session streaks, Pomodoro timers, subject goals, flashcard ease factors, and custom settings remain 100% intact across every version update.

### 📦 GitHub Release Artifacts Guide: Why is `latest.yml` present?

When viewing [FlowTrack Pro GitHub Releases](https://github.com/SudhirDevOps1/The-Ultimate-Master-Study-Tracker/releases), you will see several files:

| Release Asset | Target Platform / Purpose | Who Should Download? |
|:---|:---|:---|
| **`FlowTrackPro.Setup.0.2.4.exe`** | **Windows 10 / 11** | End-users (standard 1-click Windows installer). |
| **`FlowTrackPro-0.2.4.AppImage`** | **Linux (Universal)** | Linux users wanting a zero-install executable. |
| **`FlowTrackPro-0.2.4.deb`** | **Ubuntu / Debian / Mint** | Linux users installing via APT or Software Center. |
| **`latest.yml` & `latest-linux.yml`** | **Electron Auto-Update Manifests** | **Required for In-App Updates**. Not intended for manual download. |

> [!NOTE]
> **Why `latest.yml` is required**: `electron-updater` requests `latest.yml` during application launch to compare local versions against GitHub releases and verify the **SHA-512 cryptographic checksum**. This ensures updates are tamper-proof and prevents corrupt downloads. Removing `latest.yml` would break the in-app auto-updater!

## ⚡ Why FlowTrack Pro?

Most productivity apps are bloated, require cloud subscriptions, or leak your activity to remote servers. **FlowTrack Pro** takes the opposite approach:
1. **Local-First & 100% Private**: Your study logs, task titles, active apps, and whiteboard drawings never leave your local device.
2. **Ultra-Low Resource Footprint**: Tuned to run with minimal RAM (~100-150MB across Main + Renderer processes) and **< 0.5% CPU** usage during background focus sessions.
3. **No Setup Friction**: Works instantly in the browser as a progressive web app or as a standalone zero-config desktop application.

> [!IMPORTANT]
> **Active-Only Webview RAM Optimization**: FlowTrack Pro renders only the active browser tab in DOM memory. Background tabs are dynamically suspended, preventing multi-process Chromium memory bloat and slashing RAM from **1GB+ down to ~120MB**.

## 🚀 Quickstart Guide

### 1. 🌐 Web App (Development)
```bash
# Clone the repository
git clone https://github.com/SudhirDevOps1/The-Ultimate-Master-Study-Tracker.git
cd The-Ultimate-Master-Study-Tracker/web-app

# Install dependencies and start Vite dev server
npm install --legacy-peer-deps
npm run dev
```

### 2. 🖥️ Desktop App (Electron)
```bash
cd desktop-app

# Install dependencies
npm install --legacy-peer-deps

# Run in development mode (Vite + Electron with hot reload)
npm run electron:dev

# Build production standalone installers (.exe)
npm run electron:build
```
